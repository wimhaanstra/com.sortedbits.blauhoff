BlauHoff provides smart home and business battery solutions.

This app adds Homey support for BlauHoff hybrid inverters and for BlauHoff BLH-5100 home batteries. If your battery is already connected to CFE Group through the Smart Energy PLAT cloud, you can add it to Homey with the same account you use in that app.

Hybrid inverters currently supported:

1. Deye Sun *K SG01HP3 EU AM2 Series
2. Afore AF XK-TH Three Phase Hybrid Inverter

These inverters work locally using a Modbus to Modbus TCP adapter, or using the Solarman Network adapter.

When you are using Solarman, you need to enter the INTERNAL IP address of your Solarman network adapter and (probably) port 8899.
